Display : Flex (Child Property) Flex - Basis

  • The flex-basis CSS property sets the initial main size of a flex item. It sets the size of the content box unless otherwise set with box-sizing.

Display : Flex (Child Property) Flex - Grow

  • The flex-grow CSS property sets the flex grow factor, which specifies how much of the flex container's positive free space, if any, should be assigned to the flex item's main size.
  • When the flex-container main size is larger than the combined main sizes of its flex items, this positive free space can be distributed among the flex items, with each item's growth being their growth factor value as a proportion of the sum total of all the flex items' flex grow factors.
Flex-grow: Auto
Flex-grow: 1.
Flex-grow: 2


Display : Flex (Child Property) Flex-shrink

  • The flex-shrink CSS property sets the flex shrink factor of a flex item. If the size of all flex items is larger than the flex container, the flex items can shrink to fit according to their flex-shrink value.Each flex item's negative free space is distributed between the line's flex items that have a flex-shrink value greater than 0.
Flex-shrink: 0
Flex-shrink: 1
